# 注释规范

## 通用要求

- 注释统一使用中文。
- 注释只补充业务语义、边界条件和实现意图，不要写无效注释或逐行翻译代码。
- 不要用注释弥补糟糕命名；能通过命名表达清楚的内容，优先改命名。
- 若使用常见短名/缩写（如 `cfg`、`ctx`、`ref`、`prev`、`next`），必须在定义处补中文注释说明业务语义。

## 注释格式

- 变量、计算属性定义使用中文 `/** */` 注释。
- 方法定义注释使用 JSDoc（`/** ... */`）。
- 方法体内注释统一使用中文 `//`。

## Vue `script setup`

适用于 `.vue` 文件（`<script setup>`），包括 Vue / Admin / UniApp 场景。

- `ref`、`reactive` 响应式数据定义需补 `/** */` 注释。
- `computed` 计算属性定义需补 `/** */` 注释。
- 通用方法、`axios*Api`、`handle*` 事件处理函数定义需补 JSDoc 注释。
- 方法体内如需解释局部逻辑，统一使用中文 `//`，避免堆砌无意义注释。
