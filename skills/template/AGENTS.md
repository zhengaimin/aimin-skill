# Aimin-skill

<!-- aimin-skill-version: 0.1.3 -->

本文件作为项目规则入口，只保留通用工作边界与规则路由；具体规范在命中场景后按需读取 `.agent/**` 文件。

## 工作方式

### 读取规则

- 先检查当前任务、目录结构和相关代码，再决定需要读取的规则文件。
- 默认不预读全部 `.agent/**`；命中具体场景后，再按路由表读取对应文件。
- 项目侧规则优先级高于通用模板；规则文件缺失时，优先遵守当前代码风格与本文件约束。

### 修改边界

- 只实现当前任务需要的最小改动，不添加未请求的功能、抽象、配置化或未来扩展点。
- 只修改与任务直接相关的文件；不顺手重构、格式化、改写注释、删除旧代码或清理无关问题。
- 只清理本次改动造成的未使用导入、变量和函数；发现无关问题时，在交付说明中单独指出。

### 代码注释

- 新增或修改代码时，同步检查注释是否需要补充、调整或删除；具体范围、格式和边界以 `.agent/comment.md` 为准。

### 文档与收尾

- 涉及第三方库、框架、SDK 或依赖 API，且存在版本差异或不确定时，先使用 Context7 MCP 查询最新文档。
- 只要本次会话修改了代码，收尾时必须按 `.agent/scripts/lint.md` 对本次修改文件执行 lint；优先按文件路径或最小范围执行，不默认全量执行。

### 项目级别规则

- 由 `/am:archive` 维护，使用表格记录“修改范围 / 对应归档文档 / 读取要求 / 备注”。
- 修改某个功能点、页面或模块前，先读取对应 `.agents/archive/**` 文档，再结合当前用户 prompt 进行确认。
- 修改代码后，把关键变更、影响范围和待确认事项回写到对应归档文档。
- 不要覆盖 `# Aimin-skill` 受管段落，也不要把项目独有规则写回模板基线。
