# Aimin-skill

本项目采用渐进式披露：默认先读本文件，命中具体任务后再进入对应的 `.agent/**` 文件或现有业务代码。

## 工作方式

### 读取规则

- 先检查当前代码、目录与用户任务，不默认预读全部 `.agent/**` 规范。
- 渐进式读取规则：命中具体场景后，再读取路由表中的对应文件；缺失时优先遵守当前代码风格与根文档约束。
- 项目侧规则优先级高于通用模板；编写代码时优先遵守项目现有风格，命中细分规则后再按对应 `.agent/**` 执行。

### 修改边界

- Simplicity First：只写解决当前问题所需的最少代码，不加未请求的功能、抽象、配置化或未来扩展点；单次使用的逻辑不要抽成公共层。
- Surgical Changes：只修改与任务直接相关的代码；不顺手重构、格式化、改注释、删除旧代码或清理无关问题。
- 清理边界：只清理本次改动造成的未使用导入、变量、函数；发现无关问题只在交付中说明。

### 文档与收尾

- 涉及第三方库、框架、SDK、依赖 API，且存在版本差异或不确定时，先使用 Context7 MCP 查询最新文档。
- 会话中只要修改了代码，收尾时必须按 `.agent/scripts/lint.md` 对本次修改文件执行 lint；优先按文件路径或最小范围执行，不默认全量执行。

## 路由表

| 场景 | 读取文件 | 说明 |
| ---- | -------- | ---- |
| 接口新增、接口更新 | 当前接口目录、`.agent/index/constants.json`、`.agent/index/utils.json`、`.agent/api.md`（若存在） | 接口落点、类型命名、枚举协同 |
| 系统常量、枚举维护 | `.agent/index/constants.json` | 常量索引、文件位置、枚举值摘要 |
| 公共方法、工具函数 | `.agent/index/utils.json` | 公共方法索引、用途、文件位置 |
| 注释规范 | 当前项目现有注释风格、`.agent/comment.md`（若存在） | 注释语言、格式与使用边界 |
| 命名、代码顺序 | 当前项目现有实现、`.agent/naming.md`（若存在） | 通用命名与代码组织规范 |
| lint、交付收尾 | `.agent/scripts/lint.md` | 收尾检查与交付前清单 |
